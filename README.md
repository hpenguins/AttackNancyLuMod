# 集火南希露 AttackNancyLuMod 1.1.0

在战斗中一键向全场广播「集火目标」，支持将准星标点指向任意玩家或怪物。鼠标悬停在战场 3D 角色模型或顶部 HUD 玩家头像上，按下快捷键即可秒发标点短语并播放头顶集火动画。

短语广播与特效完全复用游戏原生标点协议，未安装本模组的其他玩家客户端同样能够正常看见角色名称与头顶动画。

## 主要特性

- **一键快捷集火**：无需开启轮盘拖动选择，鼠标指向目标按下快捷键（默认 `X`）即可立即标点。
- **全目标支持**：支持怪物、敌方玩家、友方队友以及自己（整活娱乐）。
- **HUD 头像联动**：鼠标悬停在屏幕上方玩家头像栏上按下快捷键，亦可精准标记该玩家。
- **PVP 标点系统解锁**：解除游戏原版在 PVP 模式中隐藏标点按钮和禁用快捷键的限制，支持在 PVP 派对中完整使用标点系统。
- **可选战术标点扩展**：除集火外，支持额外绑定「小心目标」与「我来解决」独立快捷键。
- **可选覆写标点轮盘**：开启后，游戏原生标点轮盘的玩家页会改成「小心 / 集火 / 我来解决」三条，队友与自己也能直接点选；关闭时保持原版内容。

## 安装

需要 CesiumLoader SDK 2.8.6 或更高版本。将 `AttackNancyLuMod` 文件夹复制到游戏 `AstralParty_ModLoader/mods/` 目录下，重启游戏即可生效。

## 配置

修改 `config.json`，保存后约 1 秒自动热重载：

- `enabled`：总开关，默认 `true`。
- `focusKey`：一键集火快捷键，默认 `X`。
- `warnKey`：一键小心快捷键，默认留空不启用。
- `tackleKey`：一键我来解决快捷键，默认留空不启用。
- `screenRadius`：3D 角色屏幕吸附检测半径（像素），默认 `100.0`。
- `unlockPvpMark`：是否在 PVP 模式中解锁原生标点系统与标点按钮，默认 `true`。
- `allowSelfFocus`：鼠标悬停在自己身上时是否允许发出集火自己标点，默认 `true`。
- `overrideWheel`：是否把原生标点轮盘的玩家页覆写为「小心 / 集火 / 我来解决」，默认 `false`。开启后队友与自己的轮盘会切成这三条（原版的准备治疗 / 准备转账 / 准备发牌 / 技能不再显示）；地面与卡牌标点不受影响。关闭 `allowSelfFocus` 时，自己仍保持原版轮盘。
